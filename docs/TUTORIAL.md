# dsh-douyin-note 部署教程

> 面向**第一次装的人**。照着从头做到尾，大约 10 分钟（其中装依赖和扫码各占一会儿）。
>
> 插件是干什么的：让 DeepSeek Harness 里的助手帮你**发抖音图文** —— 传图、填标题描述、挂话题、搜配乐、选可见性，最后点真实的「发布」按钮。默认**干跑**（表单填好、点发布，但作品不会发出去），你说「可以」才真发。还能设个频率让它自己写稿、自己配图、自己发。

---

## 0. 先确认你有没有这些

| 需要 | 怎么确认 | 没有怎么办 |
|---|---|---|
| 能正常用的 **DeepSeek Harness** | 能打开 Web 界面、能跟助手对话 | 先装好 DSH |
| **Chrome 或 Edge** | Windows 自带 Edge 就行；macOS 装 Chrome | 装一个 |
| **能上网访问抖音** | 浏览器能打开 douyin.com | — |
| **抖音账号**（能登录网页版） | 网页版 douyin.com 能扫码登进去 | 注册一个 |
| **Python 3.9+** | 终端跑 `python --version` 能看到版本号 | Windows 用 Microsoft Store 装 Python 3.12；macOS `brew install python` |

> 🔴 **重要，先读**：抖音对「频繁发布」「新设备登录」比较敏感。**第一次用请先发一条「仅自己可见」**，确认一切正常再说。本插件第一次真发前建议先跑一次干跑（教程第 5 步）。

---

## 1. 装插件

打开终端（Windows：PowerShell；macOS：终端），粘贴：

```bash
dsh plugin --profile desktop add github:Lyuchen0720/dsh-douyin-note
```

> `--profile desktop` 换成你自己的 profile 名。不确定就填 `desktop`（桌面版默认）。

看到类似 `added 1 bundle` 就是成了。**装完必须重启一次 DSH**（插件要在启动时组装，光刷新网页不够）。

**重启后自查**：跟助手说一句

> 「用 douyin_note_status 看看状态」

能返回一段 JSON（里面有 `home`、`profile`、`chrome_alive`）就说明插件装好了。

---

## 2. 装运行环境（约 30 秒）

进 **设置 → 刷抖音**（注意是「刷抖音」，不是「抖音图文」——前者是本插件自带的登录/浏览器模块，设置页在它那边），点 **「装主依赖」**。

它会在 `~/.dsh/douyin-duty/.venv` 建一个独立 Python 环境，装 `curl_cffi` 和 `httpx`。看到「环境就绪」即可。

> 装不动、卡在下载：先点「修复运行环境」再试；还不行就检查网络/代理。
> 这一步**只影响「刷抖音」自己的取数功能**，发图文本身用的是浏览器，所以这一步失败也还能发，但建议装好，省得后面排查。

---

## 3. 扫码登录（只做一次）

还是 **设置 → 刷抖音**，点 **「扫码登录」**。

会**弹出一个真的 Chrome 窗口**（这是唯一会开窗口的地方），页面停在抖音登录二维码上：

1. 手机打开抖音 → 右上角 −→ 扫一扫
2. 扫码 → 手机上点「确认登录」
3. 电脑上的窗口会自己关掉

登录态存在 `~/.dsh/douyin-duty/chrome-profile`，以后发图文都用它。

**验证**：跟助手说

> 「douyin_note_status 传 check_login: true」

返回里 `logged_in: true` 就对了。

> 弹窗说「profile 被占用」→ 后台还有个无头浏览器开着。先在设置页停掉正在跑的任务，或者关掉所有 Edge/Chrome 进程再点一次。

---

## 4. 第一次：干跑（不会发出去）

准备一两张图（jpg/png/webp，**单张 ≤50MB**，宽高比别超过 1:2，推荐 3:4 竖图）。把图放在你电脑上一个好找的位置，比如 `E:\图片\a.png`。

跟助手说：

> 用 douyin_note_publish 发一条图文试试，先别真发：
> 图片 E:\图片\a.png
> 标题「测试一下」
> 描述「这是一次干跑」
> 话题 ["随拍"]
> 配乐「小美满」

会发生什么：

1. 后台开一个**看不见的**浏览器，打开创作者中心
2. 上传你的图 → 填标题 → 填描述 → 挂话题 → 搜索并挂上配乐
3. 滚到页面底部，点「发布」
4. **最后那一步请求被插件的拦截器取消** —— 作品不会出现在你的账号里

返回里会是：

```json
{ "ok": true, "dry_run": true, "published": false,
  "text": "测试一下。这是一次干跑 #随拍",
  "image_count": 1, "music_id": "7332070101417953282", ... }
```

**重点看返回里的 `text` 和 `image_count`**，那就是实际会发出去的内容。不对就改参数重跑干跑，不会浪费任何东西。

还有个截图：`~/.dsh/douyin-note/last-preview.png`，是点发布前的页面，能直观看到表单长什么样。

---

## 5. 第二次：真发（**要你亲口说「发」**）

确认干跑结果没问题后，跟助手说：

> 「确认，真发」

助手才会带 `confirm: true` 再调一次。成功的返回：

```json
{ "ok": true, "published": true, "aweme_id": "7711305831085657395",
  "url": "https://www.douyin.com/note/7711305831085657395", ... }
```

点那个 `url` 就能看到作品。

> 🔴 **插件只在你说「发」之后才会真发。** 助手擅自传 `confirm: true` 是违规的，返回里没有你的确认就直接当没发生。

**发错了想删**：在创作者中心 →「内容管理」→ 找到那条 →「删除作品」→「确定」。

---

## 6. 让它自己发（可选）

想让它按频率自己写、自己画、自己发：

跟助手说：

> 打开自动发布：每 12 小时一条，每天最多 2 条，**先只出草稿不发**

或者直接在 **设置 → 抖音图文** 那一页点：

- 自动发布：开
- 每 N 小时：`12`
- 每天上限：`2`
- 模式：**只出草稿** ← 先选这个
- 配乐池：改成一列你喜欢的歌名（一行一个）
- 保存 → 点「现在生成一条草稿」

草稿在 `~/.dsh/douyin-note/drafts/`，是一张 1080×1440 的文字卡 + 同名 `.json` 里写着文案。

**满意了再切「直接真发」**（设置页把模式切成「直接真发」并保存）。

| 参数 | 默认 | 意思 |
|---|---|---|
| `enabled` | 关 | 总开关 |
| `everyHours` | 12 | 每多少小时一条（最小 0.25 = 15 分钟，别设太小） |
| `perDay` | 2 | 每天最多几条（**草稿不占名额**） |
| `publish` | **关** | 关 = 只出草稿；开 = 真发（公开） |
| `musicPool` | 8 首常见歌 | 每次随机挑一个去搜 |

> ⚠️ 自动发出来的内容是**公开**的。人设文案在插件的 `prompts/persona.md` 里，想换口吻就改那个文件（改完重启 DSH）。

## 常见问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 工具表里没有 `douyin_note_*` | 装完没重启 | 完整重启 DSH |
| 设置里没有「抖音图文」 | 同上，客户端页面要重启才扫描 | 重启 DSH，再刷新网页 |
| 报 `stage: "dependency"` | 没登录 / profile 不存在 | 做第 2、3 步 |
| 报 `stage: "login"` | Cookie 过期了（一般 1–2 周） | 重新扫码登录一次（第 3 步） |
| 报 `stage: "upload"` | 图太大 / 格式不对 / 比例太夸张 | 换 jpg/png，单张 <50MB，别发超长图 |
| 报 `stage: "music"` | 歌名搜不到 | 换个常见歌名，或干脆不传 `music` |
| 报 `stage: "verify"` | 请求内容和参数对不上 | **这种情况一定没发出去**，看返回里的 `problems` |
| 报 `stage: "publish"` | 点发布后没拿到回包 | 看 `last-error.png`，多半是抖音限流，等一会儿再试 |
| 提示「profile 被占用」 | 同时起了两个浏览器实例 | 关掉所有浏览器进程再试 |
| 发出去是「仅自己可见」 | `visibility` 传了 `private` | 不传就是 `public`；`friends` 是好友可见 |

所有失败都会带一张 `~/.dsh/douyin-note/last-error.png`（出错那一刻的页面截图）和 `stage`，**照着 stage 查上表**。

## 卸载 / 换账号

**卸载插件**：

```bash
dsh plugin --profile desktop remove dsh-douyin-note
```

**数据都在 `~/.dsh/` 下**（`~` 是用户主目录；Windows 就是 `C:\Users\<你的用户名>`）：

```
~/.dsh/douyin-duty/          # 登录 profile（Chrome 用户数据）+ 刷抖音的运行数据
├── chrome-profile/          # ← 登录态就在这，删了就要重新扫码
└── .venv/                   # Python 环境（第 2 步装的）

~/.dsh/douyin-note/          # 本插件自己的东西
├── state.json               # 发布记录
├── drafts/                  # 自动模式生成的草稿
└── last-*.png               # 截图
```

**换抖音账号**：删掉 `~/.dsh/douyin-duty/chrome-profile` 整个目录，再走一次第 3 步扫码。
**彻底清干净**：删掉上面两个目录。

> 🔴 `chrome-profile` 里有你的抖音登录态，**别把它拷给别人、别传网盘**。

## 它到底在做什么（想了解原理再读）

- 不发任何「自己拼签名」的请求。全程在**真实浏览器**里操作创作者中心：真实上传、真实打字、真实点按钮。
- 真正发出去的请求是 `POST https://creator.douyin.com/web/api/media/aweme/create_v2/`，`media_type: 2` 表示图文。
- 干跑时，这条请求在浏览器里被 CDP 的 `Fetch` 拦截取消（`Fetch.failRequest`），所以服务器根本没收到。
- 每次真发前，插件会**先把这条请求的 body 解析一遍**，核对标题、描述、话题、图片数是否和你给的参数一致；不一致就直接取消并报 `stage: "verify"` —— 宁可发不出去，也不发错内容。
- 所有运行数据写在 `~/.dsh/` 下，插件包目录里不写任何东西。
